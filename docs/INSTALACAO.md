# Instalar BGeforce Now TV 0.19.0

1. Escolha uma variante: ARMv7 para Android ARM de 32 bits; ARM64 para Android ARM de 64 bits; Universal quando não souber. O sistema instalado determina a arquitetura, não apenas o processador.
2. Baixe o APK completo ou seu ZIP de instalação. Extraia o ZIP antes de abrir o APK; não renomeie ZIP para APK.
3. Transfira o APK para a TV e abra no gerenciador de arquivos. Se solicitado, autorize instalações por esse gerenciador.
4. Escolha Atualizar sobre a versão principal existente, sem desinstalar ou apagar dados. O pacote com.bgeforce.tv.main e o certificado principal são os mesmos das entregas anteriores.
5. Abra o aplicativo e selecione o jogo novamente. Conta e escolhas salvas permanecem; uma instalação nova usa Native/Compatível/720p60/H.264/8 Mbps. Full HD continua opcional em Configurações → Perfil de desempenho.

A 0.19 reconhece o canal seguro appLevelProtocol=5 e preserva a porta fornecida pelo serviço. Para NVIDIA, os dois motores pedem uma sessão WebRTC; Native continua usando WebRTC Android e MediaCodec no aparelho. A identidade do provedor permanece consistente na retomada, mesmo quando o controlador muda de domínio.

Atualize sobre a principal e tente abrir ou retomar o jogo. Se o problema persistir, use Copiar erro e envie o texto: agora ele mostra o canal selecionado e os tipos das últimas mensagens, sem corpos, tokens ou nomes de peers. Não precisa apagar dados ou enviar senha. Uma fila encerrada pelo provedor não recupera a posição.
